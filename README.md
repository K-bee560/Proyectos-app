# Librería Emmanuel

Aplicación móvil de administración para un pequeño negocio tipo ciber/librería.

## Funciones
- Inicio de sesión.
- Inventario: agregar y eliminar productos.
- Ventas: registrar ventas y descontar existencias.
- Reportes diarios de ventas y ganancias estimadas.
- Perfil y configuración de apariencia.

## Ejecutar
1. Instala las dependencias con `npm install`.
2. Inicia Expo con `npx expo start`.

Aplicación desarrollada con Expo y React Native.
